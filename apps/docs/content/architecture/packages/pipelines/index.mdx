This section is the package-family table of contents for the pipeline toolchain.

## Start Here

If you are new to the pipeline system, read the pages in this order:

1. `Core` for the DSL and definition model
2. `Loader` for discovery and import
3. `Executor` for runtime behavior
4. `Graph` for inspection and visualization
5. `Presets` and `Playground` for reusable examples
6. `Server` for the UI and control plane

## Common Entry Points

- author a DSL pipeline in [Core](/architecture/packages/pipelines/core)
- discover `.ucd-pipeline.ts` files with [Loader](/architecture/packages/pipelines/loader)
- execute definitions with [Executor](/architecture/packages/pipelines/executor)
- inspect topology with [Graph](/architecture/packages/pipelines/graph)
- run the full UI/control plane through [Server](/architecture/packages/pipelines/server)
